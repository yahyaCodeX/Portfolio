# Project: Fitness Tracker — Microservices Architecture

## Overview
A scalable fitness tracking system built using a Spring Boot microservices architecture. The system provides REST APIs for analytics, progress monitoring, and user management, with fully decoupled service communication.

## Status
- Personal project
- Year: 2025
- No live demo currently available
- GitHub: https://github.com/YahyaCodeX

## Technologies Used
- Java
- Spring Boot
- Microservices Architecture
- MySQL
- REST APIs
- Decoupled service communication (inter-service communication via REST or messaging)

## Key Features
- User management microservice
- Fitness analytics and progress tracking microservice
- Decoupled services with clean REST API boundaries
- Relational database (MySQL) for persistent storage

## Architecture
The system follows a microservices pattern where different concerns (user management, analytics, progress) are handled by separate services. Each service is independently deployable and communicates via REST APIs. This approach demonstrates Yahya's understanding of scalable, production-grade backend design.

## What It Demonstrates
This project shows Yahya's ability to:
- Design and implement microservices from scratch
- Build REST APIs using Spring Boot
- Work with MySQL for relational data persistence
- Structure a system for scalability and maintainability
