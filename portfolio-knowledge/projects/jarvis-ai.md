# Project: Jarvis Personal AI

## Overview
An advanced, personalized AI assistant powered by the Gemini Live API, capable of Windows system automation, web automation, and voice biometrics.

## Tech Stack
- **Core:** Python, Requests
- **Audio & Speech:** SpeechRecognition, pyaudio, SpeechBrain, Torchaudio
- **AI & Logic:** google-genai (Gemini API)
- **Automation:** pycaw (volume control), psutil (process management), pillow, pyautogui (screenshots), pyperclip (clipboard), selenium (browser automation), python-docx (academic document generation)

## Key Features
- **Voice Biometrics & Speech Recognition:** Uses SpeechBrain for speaker recognition and pywin32 for robust Windows SAPI text-to-speech.
- **Gemini Powered:** Leverages `google-genai` for advanced, context-aware conversational capabilities and natural language processing.
- **System Automation:** Automatically manages system processes, controls volume, reads clipboards, and takes screenshots via Python utilities.
- **Browser Automation:** Selenium integration for automating repetitive web tasks, such as university (MUET) attendance login.
- **Academic Tools:** Generates Word documents automatically for academic assignments using `python-docx`.
