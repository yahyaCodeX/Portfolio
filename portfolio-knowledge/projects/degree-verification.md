# Project: Decentralized Degree Verification System

## Overview
A secure, tamper-proof degree verification system that leverages blockchain technology and smart contracts. Enables educational institutions to issue verifiable credentials on-chain, eliminating fraud and simplifying the degree validation process.

## Status
- Featured project (most prominent in portfolio)
- Year: 2026 – Present (ongoing)
- No live demo currently available
- GitHub: https://github.com/YahyaCodeX

## Technologies Used
- Blockchain
- Web3
- Smart Contracts
- Solidity (smart contract programming language)

## Key Features
- Tamper-proof credential issuance on blockchain
- On-chain degree verification
- Eliminates traditional fraud vectors in academic verification
- Institutions can issue verifiable digital credentials

## What It Does
This system allows universities and institutions to issue degree credentials on a public or private blockchain. Graduates and employers can independently verify the authenticity of a degree without relying on paper documents or institutional intermediaries. The use of smart contracts ensures that once a degree is issued, it cannot be altered or forged.

## Why It Was Built
Traditional degree verification relies on manual institutional processes that are slow, costly, and prone to fraud. This project applies blockchain as an immutable ledger to solve this real-world problem, which is relevant in the context of academic credential fraud.

## Technical Notes
- Smart contracts handle the logic of issuing and verifying credentials
- Solidity is the language used for writing smart contracts on Ethereum-compatible blockchains
- Web3 is used to interact with the blockchain from application code
