# Project: Secure Journal App

## Overview
A backend-focused journaling application with secure CRUD operations and a clean RESTful architecture. Implements authentication and personal data management for private journal entries.

## Status
- Personal project
- Year: Academic period
- No live demo currently available
- GitHub: https://github.com/YahyaCodeX

## Technologies Used
- Java
- Spring Boot
- MongoDB (NoSQL database)
- Spring Security (authentication and authorization)

## Key Features
- Secure user authentication
- CRUD operations for journal entries
- RESTful API design
- MongoDB for flexible document-based storage
- Personal data management

## Architecture
The application follows a layered Spring Boot architecture with a security layer (Spring Security) protecting the REST endpoints. MongoDB is used as the database, making this one of Yahya's primary NoSQL projects.

## What It Demonstrates
- Spring Boot REST API development
- Spring Security integration for authentication
- Working with MongoDB in a Java context
- CRUD backend design with data security considerations

## Notes
This is a personal/academic project demonstrating backend engineering skills. It is not a commercial product.
